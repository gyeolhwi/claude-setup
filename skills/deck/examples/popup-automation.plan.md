| 항목 | 내용 |
|---|---|
| 주제 | 고객사 팝업 이미지 제작 자동화 플랫폼 |

```yaml
  - { label: 이미지 생성, value: SVG → Canvas → JPEG, desc: 완성된 팝업 화면을 캡처해 고해상도 JPG로 변환 }

  기술 스택입니다. 판독은 Canvas API와 Tesseract.js, 이미지 생성은 SVG를 Canvas로 그려 JPEG로 내보내는 방식입니다.
```

### 08 · 이미지 생성 파이프라인

```yaml
layout: pipeline
section: 기술 구조
title: 이미지 생성 파이프라인
lead: 모든 고객사가 공유하는 이미지 생성 엔진
inputs: [템플릿 (HTML/CSS), 데이터 (일정·배경·문구)]
steps:
  - { title: HTML 문서 생성 }
  - { title: 폰트·이미지 base64 인라인 변환 }
  - { title: SVG foreignObject에 삽입 }
  - { title: Canvas 렌더링 (2x) }
  - { title: JPEG 출력 (quality 0.85) }
highlight: 2
highlight_tag: 핵심
note: SVG foreignObject는 보안 정책상 외부 폰트·이미지를 불러올 수 없어, 캡처 전 모든 리소스를 base64로 인라인 변환합니다. 실패 시 1회 자동 재시도합니다.
message: 리소스 인라인 변환이 캡처 품질의 핵심
notes: |
  모든 고객사가 같은 엔진을 씁니다. 핵심은 두 번째 단계입니다.
  SVG 안에서는 외부 폰트와 이미지를 불러올 수 없어서, 캡처 전에 전부 base64로 바꿔 넣습니다.
```
